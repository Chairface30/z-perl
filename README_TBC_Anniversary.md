# Z-Perl Unit Frames BCC

Version 7.7.5 - TBC Classic Anniversary Edition
(The authoritative version number is `## Version:` in ZPerl.toc)

## Description

Z-Perl Unit Frames BCC is a complete unit frame replacement addon, evolved from Nymbia's Perl UnitFrames. It provides enhanced player, target, party, pet, focus, and raid frames with extensive customization options.

## Features

### Core Features
- Complete replacement for Blizzard's default unit frames
- Raid frames and raid tools included
- 3D Portraits for player, pet, target, focus, and party (optional)
- Configurable colors for borders, backgrounds, and class-colored names

### Combat & Tracking
- **Range Finder** - Highlights units based on spell or item range, with optional health/debuff checks
- **HoT Monitor** - Clearly highlights units with your active Heal over Time spells
- **Debuff Highlighting** - Standard debuff colors on all friendly frames, prioritizing debuffs you can cure
- **Combat Indicators** - In-combat status for all units
- **Combat Flashes** - Red/green flashes when units take damage or receive heals

### Raid Features
- **Raid Frames** - Created on demand to save memory
- **Raid Target Icons** - Support for Target, Target's Target, MT Targets
- **MT Targets** - Replacement for CTRA MT Targets window with duplicate target coloring
- **Assists View** - Shows raid members assisting you with your target
- **Casting Monitor** - Shows healer classes with mana bars, cast bars, and their targets
- **Raid Tooltips** - Shows available combat rezzers when hovering over dead players

### Raid Admin Tools
- Save/Load raid roster setups
- Item Check - Query raid for items, durability, resists
- Active Scanner - Check raid members' equipped items

### Additional Features
- Buff/debuff time remaining display
- Minimap icon and /zperl command for options
- Memory-efficient design with on-demand frame creation

## Installation

1. Extract the ZIP file to your `World of Warcraft/_classic_/Interface/AddOns/` folder
2. Ensure you have all ZPerl folders (ZPerl, ZPerl_Options, ZPerl_Player, etc.)
3. Restart WoW or type `/reload` if the game is running

## Usage

Type `/zperl` or `/xperl` in-game to open the options panel.

### Tips
- **Shift+Left-Click** on unit frames to set focus
- Use the Camera tab in options to adjust 3D portrait positioning
